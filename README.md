### Highlights

* Joint-angle based analysis
* Squat rep counting
* Movement phase detection
* Form and depth evaluation
* Client-side pose inference
* Session analytics
* FastAPI backend
* React + TypeScript frontend

### 🚧 ML Upgrade

Currently extending MotionLab with a custom ML model trained on normalized pose landmarks for:

* Correct form classification
* Shallow squat detection
* Rep-level movement scoring
* Better form intelligence

### ⚡ Performance Focus

## 🚗 RoadGuard AI

> **Computer vision powered road and driver safety assistant.**

### Planned Architecture

`Camera → Vision Models → Tracking → Risk Estimation → TTC → Local Warning`

### Building Towards

* 🕳️ Pothole detection
* 🚧 Road hazard detection
* 😴 Driver drowsiness detection
* 📵 Driver distraction detection
* 🚘 Forward collision warnings
* 🚗 Rear collision-risk estimation
* ⏱️ Time-to-Collision calculation
* 🔊 Real-time audio alerts
* 🗺️ GPS hazard mapping
* 📊 Driving safety analytics
* 📱 Edge/local inference
* 🧭 Optional IMU sensor fusion

### Core Engineering Idea

Instead of:

`Object Detection → Bounding Box`

RoadGuard aims for:

`Perception → Tracking → Risk Estimation → Decision → Warning`

### ⚡ Performance Goal

Keep safety-critical inference locally on-device to remove cloud/network latency from the warning loop.

**Tech Direction:**
`OpenCV` `Computer Vision` `Object Detection` `Tracking` `FastAPI` `Edge AI`
